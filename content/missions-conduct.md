# 📜 Code of Conduct

JunctionX Korea 2026 공식 규정. 수상 자격을 얻으려면 모두 준수해야 합니다.

- **행사 시작 이전에 작성된 코드 사용 금지**
- 지각 제출 금지
- 팀 규모는 **1~4명**
- 원격 참가 금지
- **단 하나의 챌린지에만** 참가 가능
- 혐오 발언·차별·성폭력 금지 → 발생 시 제보, 해당 인원 **즉시 퇴출**
- **소스 링크 제출 필수**, 오픈소스 라이브러리 사용 시 **반드시 명시**
- 최종 제출은 2라운드로 수집 (전 팀 제출 보장 목적)
- 결과 이의 제기: **Junction Asia 종료 후 3일 이내 공식 이메일** 접수 건만 검토

## 우리 팀 주의 포인트

> ⚠️ **agent-core 재사용 금지** — 사전 설계한 아키텍처(툴 교체형 도메인 전환)는 참고만 하고, 코드는 현장에서 새로 작성해야 합니다. 재사용하고 싶은 코드가 있다면 "행사 전에 공개된 오픈소스였는가"가 기준 — 애매하면 트랙 부스에 확인.
