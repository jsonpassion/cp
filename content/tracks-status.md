## 추가하는 방법

트랙 발표 트랜스크립트가 확보되면:

1. `content/tracks-<회사명>.md` 파일 생성
2. `content/manifest.json`의 `tracks` 탭 `subtabs`에 한 줄 추가:
   ```json
   { "id": "postech", "label": "POSTECH", "file": "tracks-postech.md" }
   ```
3. `version` 숫자를 올리고 커밋·푸시 → GitHub Pages 자동 반영

각 트랙 문서는 다음 구조를 따릅니다: **미션 한 줄 요약 → 트랜스크립트 재구성 번역 → 심사 기준(다이어그램) → 회사 리서치 → 우리 팀 관점 시사점**.
